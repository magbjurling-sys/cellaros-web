# cellaros-web

Offentlig hjemmeside for **CellarOS** — operativsystem for vinskap og private vinsamlinger.
Det norske produktnavnet er **Vinskapet**.
Serveres på [cellaros.no](https://cellaros.no) via GitHub Pages.

Dette repoet inneholder **bare** den offentlige siden. Produktkode, spekk og
strategidokumenter ligger i det private hovedrepoet.

## Innhold

```
index.html      hele siden — én fil, ingen byggesteg, ingen avhengigheter
404.html        feilside
brand/          logovarianter (SVG), app-ikon og delingsbilde (og.png)
fonts/          Newsreader + Public Sans (woff2, latin) — lokale, ingen font-CDN
CNAME           cellaros.no
robots.txt      + sitemap.xml
```

## Endre siden

Rediger `index.html` og push til `main`. GitHub Pages publiserer automatisk.
Alle farger og typografi kommer fra CellarOS-designsystemet og ligger som CSS-variabler
øverst i fila — endre tokens der, ikke enkeltverdier nedover i arket.

Siden er utformet for både lys og mørk visning, følger systemvalget til den som besøker,
og har en manuell bryter i toppen.

## Innhold og rammer

Siden er en **konseptvisning**. Alle flasker, tall og skjermbilder er eksempler.

Den er skrevet for å holde seg innenfor norsk regelverk: ingen kjøpsoppfordringer, ingen
sponsede eller produsentbetalte anbefalinger, og ingen antydning om samarbeid med
Vinmonopolet. Verdianslag presenteres som estimater, ikke som investeringsrådgivning.
Endrer du teksten, hold den innenfor det samme.
